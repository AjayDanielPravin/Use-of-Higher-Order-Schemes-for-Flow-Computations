**Use of Higher Order Schemes for Flow Computations**


**Supervisor: Dr. Manoj T. Nair**


**ABSTRACT**

This project contains an overview on the "Use of Higher Order Schemes for Flow Computations" , focusing on how to improve 

the accuracy of numerical models. It explains how errors decrease as a computational grid becomes finer and discusses methods 

for keeping high accuracy across all points in a grid. Using Fourier Error Analysis , the project compares different mathematical approaches, specifically looking at Tridiagonal and Pentadiagonal schemes. By evaluating these schemes from the 6th up to the 10th order against actual differentiation, the work shows the best ways to reduce errors in fluid flow simulations.
